# Cup of Tea
6th FEB 2026, Jiang He Zhang(Hez)

## Description
Collect everyone’s cup of tea in terms of movies

## Concept
My concept transforms a questionnaire into a playful interactive experience. Users select their favourite movie genre from tick boxes on the left, and the chosen genre then drops into a teacup. The interaction metaphorically represents collecting everyone’s “cup of tea”.

## Online Link
https://cupoftea-izm1.onrender.com/

## Technology Used
Node.js / Server
- Express: Web server framework
- Socket.IO: Real-time online interaction

Frontend Interaction / Visuals
- p5.js: Interactive graphics and user interaction
- Matter.js: Physics simulation

Security / Deployment
- HTTPS: Secure communication protocol
- Render: Project deployment and launch

## How to Run
1. Clone the repositor
2. Start the server
   ```
   npm install
   node server.js
3. Deploy on Render or any Node.js hosting service
